Tentang Kegiatan

Kegiatan ini merupakan pelatihan terstruktur untuk membangun antarmuka web modern menggunakan HTML5 semantik dan CSS Flexbox yang responsif, rapi, serta aksesibel bagi mahasiswa Fakultas Sains dan Teknologi Informasi.

Lihat Panduan Lengkap Kegiatan ↗

Syarat Peserta

  • Mahasiswa aktif program studi Teknik Informatika atau serumpun.
  • Membawa laptop pribadi dengan peramban modern dan editor kode.
  • Memahami dasar struktur dokumen HTML serta selektor CSS.

Alur Pendaftaran

  1. Isi data diri lengkap pada formulir pendaftaran di bawah.
  2. Verifikasi alamat surel aktif dan pilihan divisi peminatan.
  3. Kirim pendaftaran dan simpan bukti konfirmasi panitia.
